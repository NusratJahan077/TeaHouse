# Tea House 🍵

A responsive Tea House landing page built with HTML and Tailwind CSS.

## Features
- Hero section with banner and rating card
- Featured tea products
- Fresh tea presentation section
- Client testimonials
- News and events section
- Footer with quick links and subscription form
- Responsive layout for different screen sizes

## Technologies Used
- HTML5
- Tailwind CSS
- Font Awesome
- Google Fonts (Manrope)

## Project Structure
- `index.html` — Main webpage
- `style.css` — Custom CSS styles
- `images/` — Project images
- `README.md` — Project documentation

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
